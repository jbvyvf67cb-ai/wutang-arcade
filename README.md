# JOSHUA — A French Quarter Bear Tale

A 3D physics platformer for the web. One bear. One bow tie. One collage to finish.
One $500 plane ticket home. **The real French Quarter**, built from OpenStreetMap.

**Play it:** https://jbvyvf67cb-ai.github.io/wutang-arcade/
(deployed automatically by GitHub Actions — desktop, or a fairly recent iPhone)

## The pitch

Joshua — a smart, funny, deeply odd brown bear in a red bow tie — wakes up
face-down in the gutter outside **Lafitte's Blacksmith Shop** at 8 AM. His
collage (*"Reality is merely another kind of wonder." — Ram Dass*) is scattered
across the whole Vieux Carré: a café table at **Café du Monde**, the buskers'
stage at **Jackson Square**, the Pontalba ironwork, a skylight heist at the
Royal Street antiques shop, and the Huntress' trophy in **Pirate's Alley**.
The travel agency next to Lipstixx (300 block of Bourbon) sells flights home
for $500.

The day rolls on as you play — golden morning to neon dusk — and the Quarter
opens up with it: the voodoo shop at 10, the bars at 11, **Preservation Hall**
at 5, Lipstixx for the finale. Swim the Mississippi. Ride the Riverfront
streetcar. Drop your Groove on the Jackson Square stage and the crowd tips you.
Then assemble the collage on the sidewalk and busk your way home.

## The map is real

`tools/map/fetch_osm.py` pulls the Quarter from OpenStreetMap (raw responses
committed in `assets/map/osm_raw/`); `tools/map/build_map.py` projects it into
game space (Bourbon Street along +Z, the river at +X, 0.65× scale), triangulates
1,880 real building footprints, matches 50+ landmarks by name, and emits
`assets/map/quarter.json`. The renderer (`src/level/quarter.ts`) extrudes the
footprints with a facade atlas + per-landmark styling, hangs iron galleries on
the real gallery streets, raises the cathedral's three spires, letters every
storefront sign and street blade from real OSM names, and pours the Mississippi
past the Moonwalk (swimmable).

**Map data © OpenStreetMap contributors**, licensed under the
[Open Database License](https://www.openstreetmap.org/copyright) (ODbL).

## Group updates — request a change

Anyone can change the game: drop a plain-text request into
**`updates/queue/`** and push. Four times a day (8 AM / 2 PM / 8 PM /
midnight US Central) a scheduled Claude routine implements the queued
requests, verifies the build, publishes to the live URL, and archives each
request with a summary in `updates/processed/`. See
[`updates/README.md`](updates/README.md) for the format and
`.github/workflows/group-updates.yml` for the schedule. (Requires the
`ANTHROPIC_API_KEY` repository secret.)

## Tech

- **Babylon.js 8** + **Havok (WASM)** physics — real rigidbody character
  controller, velocity-scaled knockback, tumbling ragdolls, physics coin spills
- **Real geography**: OSM footprints triangulated offline (committed,
  reproducible), merged into 150 m chunks, distance-culled to hold the
  draw-call budget on a ~1 km map
- **Time-of-day rig** drives sun, fog, sky, lamps and neon from 8 AM to dusk;
  businesses unlock on their real-ish schedules; 7 themed enterable interiors
- **Every character is generated by scripted Blender** (`bpy`, in `tools/character/`)
  — parametric cross-section modeling, real armatures, 16 keyframed clips for
  Joshua — then exported as glTF. No primitives, no ovals.
- **Soundtrack: public-domain jazz** (Tiger Rag 1917, The Entertainer 1902,
  St. James Infirmary, When the Saints…) arranged in code (`tools/audio/`),
  rendered with fluidsynth, provenance in `assets/audio/music/manifest.json`.
  Zones follow the geography: brass on the riverfront, rag at Jackson Square,
  stomp on Bourbon, minor-key in Pirate's Alley.
- **Executable quality rubric**: `qa/playwright/rubric.spec.ts` runs the gates
  from `PLAN.md §9` plus the v2.0 gates (≥30 landmarks within 25 m of their
  OSM positions, ≥6 enterable interiors, time-of-day advance, river swim,
  full playthrough to the end card, draw-call budget) in CI before every deploy.

## Development

```bash
npm install
npm run dev          # local dev server
npm run build        # type-check + production build into dist/
npm run qa           # executable rubric (needs npx playwright install chromium)

# regenerate assets (committed, so only needed when changing the generators)
pip install bpy numpy mido lameenc pillow
python3 tools/map/fetch_osm.py             # refresh raw OSM data (network)
python3 tools/map/build_map.py             # rebuild assets/map/quarter.json
python3 tools/character/build_joshua.py    # the bear
python3 tools/character/humanoid.py        # frat boy, pirate, the Huntress
python3 tools/textures/make_textures.py    # facade atlas, signs, road
python3 tools/audio/make_shriek.py         # "I AM THE HUNTRESS..."
python3 tools/audio/make_music.py          # the 5 jazz loops (needs fluidsynth + FluidR3_GM)
```

`PLAN.md` is the design contract: full level map, economy numbers, the
complexity rubric, and milestone history. `tools/map/LANDMARKS.md` is the
landmark research table the styling draws from.
