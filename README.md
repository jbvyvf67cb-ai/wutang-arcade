# JOSHUA — A Bourbon Street Bear Tale

A 3D physics platformer for the web. One bear. One bow tie. One collage to finish.
One $500 plane ticket home.

**Play it:** https://jbvyvf67cb-ai.github.io/wutang-arcade/
(deployed automatically by GitHub Actions — desktop, or a fairly recent iPhone)

## The pitch

Joshua — a smart, funny, deeply odd brown bear in a red bow tie — wakes up
face-down in a Bourbon Street gutter at 8 AM. His collage
(*"Reality is merely another kind of wonder." — Ram Dass*) is scattered across
three blocks. The travel agency next to Lipstixx sells flights home for $500.
Find the 8 pieces. Fight the frat boys, the pirates, and the Huntress.
Charge your Groove by moving. When it's full: dance, then
**drop it like it's hot** — an 8-meter shockwave that ragdolls everything.
Assemble the collage on the sidewalk in front of Lipstixx and busk your way home.

## Controls

| | Desktop | Touch |
|---|---|---|
| Move | WASD / arrows | left virtual stick |
| Camera | mouse drag | drag right side |
| Jump / double jump | Space | JUMP |
| Claw combo | J / left click | CLAW |
| Drop It Like It's Hot | K / right click (full Groove) | pulsing DROP IT |
| Fishbowl (15s invincibility, costs 1 HP) | F | 🐠 |

## Tech

- **Babylon.js 8** + **Havok (WASM)** physics — real rigidbody character
  controller, velocity-scaled knockback, tumbling ragdolls, physics coin spills
- **Every character is generated by scripted Blender** (`bpy`, in `tools/character/`)
  — parametric cross-section modeling, real armatures, 16 keyframed clips for
  Joshua — then exported as glTF. No primitives, no ovals.
- **Soundtrack: public-domain jazz** (Tiger Rag 1917, The Entertainer 1902,
  St. James Infirmary, When the Saints…) arranged in code (`tools/audio/`),
  rendered with fluidsynth, provenance in `assets/audio/music/manifest.json`.
  The Huntress' shriek is synthesized espeak-ng, pitch-warped and ring-modulated.
- **Executable quality rubric**: `qa/playwright/rubric.spec.ts` runs the gates
  from `PLAN.md §9` (zero console errors, clip manifest, collision sampling,
  shockwave ragdoll behavior, fishbowl rules, KO coin spill, full playthrough
  to the end card, draw-call budget) in CI before every deploy.

## Development

```bash
npm install
npm run dev          # local dev server
npm run build        # type-check + production build into dist/
npm run qa           # executable rubric (needs npx playwright install chromium)

# regenerate assets (committed, so only needed when changing the generators)
pip install bpy numpy mido lameenc pillow
python3 tools/character/build_joshua.py    # the bear
python3 tools/character/humanoid.py        # frat boy, pirate, the Huntress
python3 tools/textures/make_textures.py    # facade atlas, signs, road
python3 tools/audio/make_shriek.py         # "I AM THE HUNTRESS..."
python3 tools/audio/make_music.py          # the 5 jazz loops (needs fluidsynth + FluidR3_GM)
```

`PLAN.md` is the design contract: full level map, economy numbers, the
complexity rubric, and milestone history.
